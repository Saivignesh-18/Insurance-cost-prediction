# Insurance Cost Predictor

A full-stack machine learning web application that predicts insurance costs
based on user inputs using a Linear Regression model.

## Live Demo
[Click here to view the app](https://insurance-predictor.onrender.com)

## Features
- Predicts annual and monthly insurance premium
- Risk level indicator (Low / Medium / High / Very High)
- Factor contribution bar chart
- Real-time prediction via REST API

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| ML Model | Scikit-learn Linear Regression |
| Data Processing | Pandas, NumPy |
| Deployment | Render |

## ML Model Performance
- Algorithm: Linear Regression
- R² Score: 96.6%
- MAE: $1,525
- RMSE: $1,955

## Input Features
- Age
- BMI
- Number of children
- Sex
- Smoking status
- Region
